# S3.3 Feedback is a box's own feedback page, over every track's feedback notes

## Requirement

> For feedback I think we can use the exact same feedback that we use on each track

Zach, Daily Note - Nov 24 2026, # Vibe tracks. Quoted exactly. [OBJECTIVES.md §4](../OBJECTIVES.md#4-the-spec) lists every item; this note
explains it and never overrides it.

## What it means

Feedback shows every box's `feedback/*.md` notes as rows of the same data-ui view and presets a box's
Feedback tab uses, plus a Track column and a group-by-track preset. Adding feedback here asks which track and writes
one note into that box's `feedback/`, in the box's format, which is the one write into a box Vibe Tracks makes
(S1.2).

## Why

Zach's words. Same reasoning as S3.2.

## How it is checked

`S3.3 *`: two fixture boxes' feedback notes all listed with their track; the side panel opens the note; adding
one from the page writes exactly one new file under the chosen box's `feedback/` and nothing else in any box.
