# S2.4 Right-click on a track opens the same menu as its ···

## Requirement

> When I right click the sidebar, I should get the same drop down menu that I would get if I click the 3 dots

Zach, PROJECT - Vibe Tracks, # DPs › Sidebar (Oct 30). Quoted exactly. [OBJECTIVES.md](../OBJECTIVES.md) lists every item; this note
explains it and never overrides it.

## What it means

A right-click on a track row opens the ··· menu at the pointer, never the browser's own menu. A row being
renamed keeps the browser's menu (Paste must work while typing).

## Why

Built Oct 30 (`c5655a9`); held here so the menu rewrite (S2.3) keeps it.

## How it is checked

`S2.4 *`: a real right-click opens a menu whose items equal the ··· menu's, at the pointer (within 4 px).
