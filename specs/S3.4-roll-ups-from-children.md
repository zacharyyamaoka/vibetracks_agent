# S3.4 A parent rolls up its children: state and number of agents

## Requirement

> its vibe tracks though that can like roll up certain measurements from the children for example like state, number of agents etc.

Zach, Daily Note - Nov 24 2026, # Vibe tracks. Quoted exactly. [OBJECTIVES.md §4](../OBJECTIVES.md#4-the-spec) lists every item; this note
explains it and never overrides it.

## What it means

A parent row (sidebar and Home) shows its own state, plus a pip when a descendant is worse, and the number of
agents working across its subtree. Roll-ups read only what each box already publishes (`status.json`
`ai-team-status/1`, `site/data/state.json`), never a field a box adds for Vibe Tracks.

## Why

Zach's words; the "worse sub-track shows as a pip" rule is his Oct 14 one (PROJECT - Vibe Tracks).

## How it is checked

`S3.4 *`: a fixture parent with children blocked + running and 2 + 1 agents shows the pip and 3 agents; changing
one child's `status.json` on disk updates the parent within 5 s.
