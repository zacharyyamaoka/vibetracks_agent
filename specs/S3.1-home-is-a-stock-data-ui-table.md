# S3.1 Home is a stock data-ui table of tracks, folding by parent, with Active / Done / All tracks presets

## Requirement

> the home view I think to me just looks like a stock data-ui table with perhaps a couple of different views
>
> we have some quick pressets we can filter it by and of course its like hericaily so you can expand and fold as you desire

Zach, Daily Note - Nov 24 2026, # Vibe tracks. Quoted exactly. [OBJECTIVES.md](../OBJECTIVES.md) lists every item; this note
explains it and never overrides it.

## What it means

Home is one data-ui `<data-views>` over one row per track (no hand-drawn table): rows nested by Vibe Tracks'
tree with a fold chevron per parent, columns read from each box (state, objective and its value, agents working,
last activity, waits), and quick presets **Active**, **Done** and **All tracks** as data-ui views of the same rows,
Active first. Other views (board, cards) may follow as more presets of the same rows.

## Why

Zach's words, and the stock-data-ui rule he gave for every black-box tab the same day ("I like how we use stock
data Ui for each thing so like its super easy to just know the design langaugue").

## How it is checked

`S3.1 *`: the Home page holds a `data-views` element; its presets are Active, Done, All tracks in that order;
folding a parent hides exactly its descendants; the Done preset shows only done fixture boxes.
