# S4.2 The New track dialog writes the command to copy, and can run it

## Requirement

> Ok love this cool how it makes the CLI command that you copy and run...
>
> I don't like how I need to do it from the CLI. I 100% should have the option to just run it from within the GUI.

Zach, Daily Note - Nov 24 2026, # Vibe tracks; PROJECT - Vibe Tracks, # DPs › Creating new Tracks (Oct 30). Quoted exactly. [OBJECTIVES.md §4](../OBJECTIVES.md#4-the-spec) lists every item; this note
explains it and never overrides it.

## What it means

New track opens a dialog with Name, Under (the parent), and **Publish to GitHub** (off by default). The command
line under them is the exact `vt new …` the fields make, updated as you type, with **Copy command**. A **Create** button
runs that same command (Oct 30's ask; parity: the page and the CLI do the same thing), and the new track appears
in the sidebar at once.

## Why

Nov 24 he liked the copyable command; Oct 30 he wanted to create from the GUI without the CLI. Both, one
command.

## How it is checked

`S4.2 *`: type a name, pick a parent, flip Publish: the command text equals the expected string each time; Copy
puts it on the clipboard; Create makes the same box the command makes, visible in the sidebar within 5 s.
