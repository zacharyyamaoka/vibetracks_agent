# S3.2 Review is a box's own review page, over every track's waits

## Requirement

> and for the review page we should basically be using the exact same like review page we do for each track the only difference is now we incluide the things accross all of the tracks..

Zach, Daily Note - Nov 24 2026, # Vibe tracks. Quoted exactly. [OBJECTIVES.md](../OBJECTIVES.md) lists every item; this note
explains it and never overrides it.

## What it means

Review uses the same component a box's site uses for what waits on Zach (the viewer's Needs-you), fed the union
of every box's open items, each carrying its track. It adds a Track column and a group-by-track preset, nothing else.
Opening an item opens it in its box's page.

## Why

One review look to learn, once; a box's page and the roll-up can never drift apart.

## How it is checked

`S3.2 *`: two fixture boxes with one wait each: both on Review, each labelled with its track; the component's
element is the same one the box's own site uses; clicking one opens its box's page.
