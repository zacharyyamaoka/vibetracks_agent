# S2.3 The ··· menu on a track has Claude's items, in Claude's order, with its shortcut letters

## Requirement

> of course on each track we can also support like this 3 dot menu as well

Zach, Daily Note - Nov 24 2026, # Vibe tracks (screenshot of Claude's menu: Open in ›, Unpin P, Mark as unread U, Rename R, Fork F, Move down, Move to section ›, Archive A, Delete D). Quoted exactly. [OBJECTIVES.md](../OBJECTIVES.md) lists every item; this note
explains it and never overrides it.

## What it means

A track's ··· menu reads, top to bottom: **Open in ›** (the box's site in a browser tab, its folder, its
GitHub repo when it has one) · **Pin / Unpin** `P` · **Mark as unread / read** `U` · **Rename** `R` (Vibe Tracks'
label only, S1.2) · **Fork** `F` (a new box duplicated from this one, S4.1) · **Move up / Move down** · **Move to
section ›** · **Pause / Resume** `Z` (S2.10: Pause on an active track, Resume on a paused one; ruler v2,
[PEP 0002](../docs/peps/0002-ruler-v2-pause-resume.md), where Zach named it: *"in the 3 button menu You can give like a
pause/resume, archive, delete"*) · **Archive** `A` (hidden from the sidebar, the box untouched) · **Delete** `D` (in red: removes the track
from Vibe Tracks; the box's folder and repo are never deleted from here). Separators where Claude has them. Vibe
Tracks' own extras (New sub-track…) come after Claude's items, behind a separator. Each shortcut works while the menu
is open.

## Why

Zach's screenshot of Claude's menu is the spec. On main today the menu has three items (Rename, New sub-track…,
Share…), as the Oct 30 AI callout in PROJECT - Vibe Tracks already said.

## How it is checked

`S2.3 *`: the menu's item labels, in order, equal the list above (Move up absent on the first row; Pause or Resume
by the row's state); pressing each letter runs its item (`Z` pauses an active track and resumes a paused one); Delete
leaves the box's folder on disk.

Ruler v2 ([PEP 0002](../docs/peps/0002-ruler-v2-pause-resume.md)) put Pause / Resume `Z` right before Archive; `Z`
because P is Pin's letter and Z is free.
