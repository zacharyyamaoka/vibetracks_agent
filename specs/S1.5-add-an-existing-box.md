# S1.5 Add a box that already exists: a folder, or a GitHub repo to clone

## Requirement

> on my computer I basically like download the blackbox agent repos

Zach, Daily Note - Nov 24 2026, # Vibe tracks. Quoted exactly. [OBJECTIVES.md](../OBJECTIVES.md) lists every item; this note
explains it and never overrides it.

## What it means

`vt add <folder | github url> [--parent <track>]` lists an existing box as a track (a URL is cloned first). The
page has the same action (Principle #1). Adding a folder that is not a black-box repo says why and lists nothing.

## Why

Most boxes exist already (trajectory_tracking_agent, claude_party_agent, robot_sdk_agent …). "Download the
repos" has to be one step.

## How it is checked

`S1.5 *`: `vt add <fixture box folder> --parent <track>` puts it under that parent in the sidebar; adding a plain
folder exits non-zero, names what is missing, and the tree file is unchanged.
