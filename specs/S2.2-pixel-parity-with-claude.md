# S2.2 Pixel parity with the Claude desktop app's sidebar

## Requirement

> Please take a look at the claude GUI and basically do a pixel perfect copy... / Its nice not having to relearn new UIs.
>
> In terms of the side bar we can copy claudes GUi basically exactly

Zach, Daily Note - Nov 24 2026, # Vibe tracks. Quoted exactly. [OBJECTIVES.md §4](../OBJECTIVES.md#4-the-spec) lists every item; this note
explains it and never overrides it.

## What it means

Type (family, size, weight), row height, padding, corner radius, hover and selected fills, section-header
style, the ··· button's place and its hover state, and the status dot match Claude's sidebar in light and dark.

## Why

Zach lives in Claude's sidebar all day; matching it means nothing to relearn. Same rule as
[[user_specs_by_reference_app]].

## How it is checked

`S2.2 *`: computed styles of a plain row, a hovered row, the selected row and a section header, in both themes,
against reference values measured from Claude's own sidebar. Each reference value names where it was measured
(`ruler/reference/claude-sidebar.json`); a property with no measured reference is not checked and is listed as such.
A side-by-side capture against Zach's Claude screenshots goes in the run's report (diagnostic, not scored).
