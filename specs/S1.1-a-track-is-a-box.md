# S1.1 A track is a black-box agent repo on this machine, and opening it shows that box's own site

## Requirement

> All vieb tracks now is though is just a side bar
>
> on my computer I basically like download the blackbox agent repos / And when you click each page that is eaxactly what it ends up showing.

Zach, Daily Note - Nov 24 2026, # Vibe tracks. Quoted exactly. [OBJECTIVES.md §4](../OBJECTIVES.md#4-the-spec) lists every item; this note
explains it and never overrides it.

## What it means

A track is one black-box agent repo (the blackbox_agent format: README, OBJECTIVES.md, specs/, feedback/,
ledger.jsonl, site/ …) in a folder on this machine. Clicking its row in the sidebar shows that box's own site in the
main pane, exactly as the box builds it (`site/index.html`, its dashboard under `site/dashboard/`), served locally.
Vibe Tracks draws nothing of its own inside a box's page. A box with no built site shows its README.

## Why

Each box already ships its full page (spec, feedback, iterations, gates, agents). Rebuilding those pages inside
Vibe Tracks is the work that made it "not that helpful" (W2 retro, Nov 21). The sidebar plus the box's own page is
the whole app, apart from the three roll-up pages (§3).

## How it is checked

`S1.1 *` in the acceptance run: three fixture boxes, each with its own `site/index.html` carrying a marker text.
Clicking each row puts that box's marker on screen in the main pane (measured by its bounding box, not DOM presence),
and the address bar names the track. A fixture box with no `site/` shows its README's first heading.
