# S1.4 A box's data changing on disk shows on its page live

## Requirement

> The cool thing is beacuse its local, we can literatly like see the data updating live.
>
> And for example now in the agents page... you could actually like see them working more live etc..

Zach, Daily Note - Nov 24 2026, # Vibe tracks. Quoted exactly. [OBJECTIVES.md §4](../OBJECTIVES.md#4-the-spec) lists every item; this note
explains it and never overrides it.

## What it means

While a box's page is open, a change to that box's files on disk (a new ledger row, a rebuilt
`site/data/state.json`, a new feedback note) reaches the page within a few seconds, with no reload of the sidebar and
no lost scroll or selection. The Agents page shows agents working as they work.

## Why

Local boxes are the reason this beats the published GitHub Pages copy: the page can be live.

## How it is checked

`S1.4 *`: with a fixture box open, the test rewrites its site's marker text on disk; the new text is on screen
within 5 s, `history.length` is unchanged and the sidebar's scroll position is the same.
