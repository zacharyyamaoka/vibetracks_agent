# S2.6 The view menu: Group by, Sort by, Show, New section, Reset to defaults, View all

## Requirement

> so one goruping is for example all of them flat shorted by recent / One could be to group it by like the parents, etc...

Zach, Daily Note - Nov 24 2026, # Vibe tracks (screenshot of Claude's menu: Group by › None, Sort by › Last updated, Show ›, New section, Reset to defaults, View all). Quoted exactly. [OBJECTIVES.md](../OBJECTIVES.md) lists every item; this note
explains it and never overrides it.

## What it means

The tracks list has Claude's header with the filter icon on the right; it opens a menu with **Group by ›**
(None, Parent, State), **Sort by ›** (Manual, Last updated, Created, Name), **Show ›** (which rows show: archived,
done), a separator, **New section**, a separator, **Reset to defaults**, **View all**. Each submenu shows its current
pick on the right, as Claude does. The choice survives a restart.

## Why

Zach's screenshot of Claude's menu is the spec. The defaults (Group by Parent, Sort by Manual) are today's tree,
so nothing moves until he picks otherwise.

## How it is checked

`S2.6 *`: the menu's entries in order; each submenu's options; the current pick shown on the right; Reset to
defaults restores Parent + Manual; New section asks for a name and adds an empty section.
